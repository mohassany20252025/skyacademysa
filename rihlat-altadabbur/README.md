# مشروع "رحلة التدبر" — ألعاب تفاعلية في تفسير سورة إبراهيم (الآيات 43 إلى 52)

تطبيق ويب تعليمي تفاعلي متكامل باللغة العربية واتجاه **RTL**، مصمم لطلاب **الصف الأول الثانوي** في مادة **التفسير** (تفسير سورة إبراهيم: الآيات 43–52). يجمع التطبيق بين 6 ألعاب تعليمية تفاعلية مبنية على مبادئ التعلم القائم على اللعب (Game-Based Learning) ولوحة تحكم تحليلية شاملة للمعلم مدعومة بـ **Firebase Authentication** و **Cloud Firestore**.

## 1. كيفية تشغيل المشروع محليًا

تأكد من تثبيت **Node.js** (الإصدار 18 أو أحدث) على جهازك، ثم نفّذ الأوامر التالية في مجلد المشروع:

```bash
# 1. تثبيت الحزم والاعتماديات
npm install

# 2. نسخ ملف البيئة التجريبي
cp .env.example .env

# 3. تشغيل خادم التطوير المحلي (Vite)
npm run dev
```

سيعمل التطبيق على الرابط `http://localhost:5173`.
> **ملاحظة:** إذا شغّلت المشروع قبل إدخال مفاتيح Firebase في ملف `.env`، سيعمل التطبيق تلقائيًا في **وضع العرض التجريبي (Demo Mode)** مع تنبيه واضح بأن النتائج تحفظ محليًا على الجهاز ولا تتزامن بين الأجهزة إلا بعد ربط Firebase.

## 2. كيفية إنشاء مشروع Firebase

1. افتح منصة [Firebase Console](https://console.firebase.google.com/).
2. اضغط على **Add project** (إضافة مشروع) واكتب اسم المشروع مثلًا: `rihlat-altadabbur`.
3. يمكنك تعطيل Google Analytics أو تفعيله حسب رغبتك، ثم اضغط **Create project**.
4. من الصفحة الرئيسية للمشروع، اضغط على أيقونة الويب **`</>`** لإضافة تطبيق ويب جديد.
5. سمِّ التطبيق `rihlat-altadabbur-web` ثم اضغط **Register app**.
6. احتفظ بكائن إعدادات `firebaseConfig` الذي سيظهر لك لاستخدامه في الخطوة السابعة.

## 3. كيفية تفعيل Anonymous Authentication للطلاب

يستخدم التطبيق المصادقة المجهولة (**Anonymous Authentication**) للطلاب حتى يتمكن كل طالب من إنشاء محاولاته وتحديث إجاباته بأمان دون طلب بريده الإلكتروني أو أي بيانات شخصية إضافية:

1. من القائمة الجانبية في Firebase Console، اختر **Build** > **Authentication**.
2. اضغط على **Get started** (إذا كانت المرة الأولى).
3. انتقل إلى تبويب **Sign-in method**.
4. اختر **Anonymous** من قائمة مزودي الدخول.
5. فعّل الخيار **Enable** ثم اضغط **Save**.

---

## 4. كيفية تفعيل Email/Password Authentication

تُستخدم مصادقة البريد وكلمة المرور لحماية لوحة تحكم المعلم:

1. في نفس تبويب **Sign-in method** داخل **Authentication**.
2. اضغط على **Email/Password**.
3. فعّل الخيار الأول **Email/Password** (لا حاجة لتفعيل Email link).
4. اضغط **Save**.

---

## 5. كيفية إنشاء حساب المعلم بالبريد الداخلي وكلمة المرور المحددين

يُحظر تخزين كلمة مرور المعلم في ملفات JavaScript أو إظهارها في واجهة الطلاب. يتم إنشاء الحساب مباشرة في Firebase Authentication:

1. من داخل **Authentication**، انتقل إلى تبويب **Users**.
2. اضغط على زر **Add user** (إضافة مستخدم).
3. أدخل بيانات حساب المعلم المعتمدة:
   - **Email (البريد الداخلي):** `teacher@tafsir-game.com`
   - **Password (كلمة المرور):** `mo1234`
4. اضغط **Add user**.
5. في شاشة دخول المعلم داخل التطبيق، يظهر **حقل كلمة المرور فقط**، ويقوم التطبيق بإرسال البريد الداخلي `teacher@tafsir-game.com` مع كلمة المرور المدخلة إلى Firebase Authentication للتحقق الآمن.

## 6. كيفية إعداد قاعدة بيانات Cloud Firestore وقواعد الأمان

1. من القائمة الجانبية في Firebase Console، اختر **Build** > **Firestore Database**.
2. اضغط على **Create database**.
3. اختر الموقع الجغرافي الأقرب (مثل `eur3` أو `me-central1`) ثم اضغط **Next**.
4. ابدأ بوضع **Production mode** ثم اضغط **Create**.
5. انتقل إلى تبويب **Rules** داخل Firestore Database، وانسخ محتوى ملف `firestore.rules` الموجود في جذر المشروع والصقه بالكامل، ثم اضغط **Publish**.

### ماذا تضمن قواعد `firestore.rules`؟
- **للطلاب (Anonymous Auth):** يسمح للطالب بإنشاء وثيقة محاولة في مجموعة `attempts` وتحديثها أثناء تقدمه في اللعبة بشرط أن يتطابق `request.resource.data.studentUid == request.auth.uid`.
- **منع قراءة بيانات الآخرين:** لا يستطيع أي طالب قراءة محاولات أو إجابات أو درجات الطلاب الآخرين.
- **للمعلم فقط:** وحده الحساب المصادق عليه بالبريد `teacher@tafsir-game.com` يملك صلاحية قراءة جميع المحاولات في لوحة تحكم المعلم وتصدير التقارير.

## 7. كيفية وضع إعدادات Firebase داخل ملف البيئة (.env)

افتح ملف `.env` في جذر المشروع وضع القيم التي حصلت عليها من Firebase Console:

```env
VITE_FIREBASE_API_KEY="AIzaSyYourActualApiKeyHere"
VITE_FIREBASE_AUTH_DOMAIN="rihlat-altadabbur.firebaseapp.com"
VITE_FIREBASE_PROJECT_ID="rihlat-altadabbur"
VITE_FIREBASE_STORAGE_BUCKET="rihlat-altadabbur.appspot.com"
VITE_FIREBASE_MESSAGING_SENDER_ID="123456789012"
VITE_FIREBASE_APP_ID="1:123456789012:web:abcdef1234567890"
VITE_TEACHER_EMAIL="teacher@tafsir-game.com"
```

بعد حفظ ملف `.env`، أعد تشغيل خادم التطوير (`npm run dev`) ليتحول التطبيق تلقائيًا من وضع Demo إلى وضع الاتصال السحابي الكامل.

## 8. كيفية نشر التطبيق على الإنترنت (Deployment)

### الخيار الأول: النشر عبر Firebase Hosting
```bash
# 1. بناء نسخة الإنتاج
npm run build

# 2. تثبيت أداة Firebase CLI وتسجيل الدخول
npm install -g firebase-tools
firebase login

# 3. نشر قواعد Firestore واستضافة الموقع
firebase deploy
```

### الخيار الثاني: النشر عبر Vercel أو Netlify
1. ارفع المشروع إلى مستودع GitHub.
2. اربط المستودع بمنصة **Vercel** أو **Netlify**.
3. أضف متغيرات البيئة (`VITE_FIREBASE_*`) في إعدادات المشروع على المنصة.
4. أمر البناء: `npm run build` ومجلد المخرجات: `dist`.

## 9. كيفية اختبار صلاحيات المعلم والطلاب

1. **اختبار صلاحيات الطالب والحفظ اللحظي:**
   - افتح الصفحة الرئيسية وأدخل اسم الطالب واختر الفصل، وحاول الضغط على "ابدأ الرحلة" قبل إدخال الاسم أو الفصل للتأكد من التحقق الإلزامي.
   - ابدأ أي لعبة من الألعاب الست وأجب عن سؤالين، وستلاحظ تحديث سجل `answers` وحفظ المحاولة فورًا مع كل سؤال (`status: "in_progress"`).
   - أكمل اللعبة لتحصل على شارة الإنجاز وتتحول حالة المحاولة إلى `completed`.
2. **اختبار معالجة انقطاع الإنترنت:**
   - افصل الاتصال بالإنترنت من أدوات المطور في المتصفح (Network -> Offline) أثناء اللعب، وستلاحظ ظهور تنبيه "وضع عدم الاتصال: يتم حفظ إجاباتك محليًا ومزامنتها فور عودة الإنترنت"، وعند إعادة الاتصال تتم المزامنة تلقائيًا.
3. **اختبار لوحة المعلم والتصدير:**
   - اضغط على الرابط الصغير في أعلى الصفحة **"لوحة تحكم المعلم"**.
   - أدخل كلمة المرور في الحقل المخصص.
   - استعرض الإحصائيات العامة، جدول الطلاب، صفحة تفاصيل الطالب لكل سؤال وزمن الإجابة، تبويب التحليلات (ترتيب الطلاب، ترتيب الألعاب، أكثر الأسئلة خطأً، مقارنة الفصول)، وجرّب تصدير CSV لطالب واحد أو لجميع الطلاب وافتحه في برنامج Excel للتأكد من سلامة الحروف العربية (`UTF-8 BOM`).
